# 组件状态与回归证据矩阵

范围：当前 `packages/ui/src/components/*.tsx` 的 **60 个组件文件**与 `packages/patterns/src/*.tsx` 的 **4 个 Pattern**，合计 **64 行**。复合组件按源文件归为一行（如 Field、Form.Item、Space.Compact、Dialog 子部件）；Icons 导出不属于这 60 个组件文件，独立文档页不增加计数。

本表逐项读取测试断言及 Storybook 示例实现后整理。测试列表示**对应回归证据，执行结果以本次报告结果为准**；不是“本轮已经执行全部测试”的标记。import、导出契约、Story 存在或截图存在都不能单独证明行为通过。当前完整验证结果见 [reviews 报告目录](../reviews/) 中的 `2026-10-30-foundation-completion.md`；若报告尚未生成或没有对应运行结果，则该项执行状态仍为待核实。

状态记号：H = hover，A = 按压 active，F = focus，D = disabled，L = loading，I = invalid，R = readonly。列出的状态适用于组件自身或明确写明的内部交互部件；**未列出的 H/A/F/D/L/I/R 为组件自身不适用**，不是遗漏或默认通过。普通容器不因包含按钮就自动具有 disabled/loading/invalid。selected/current/open、错误/空态等另列；Progress 的 `status="active"` 不等于鼠标按压 active。`I（Field）` 表示组合校验语义，不表示组件自带业务校验器。

自动化证据只覆盖测试列明确描述的范围。适用但未被该列断言证明的状态均为待验收，尤其 H/A/F 的真实视觉、只读与禁用的实际输入阻断、原生系统控件、读屏播报、触摸与缩放。人工列缩写对应 [人工验收清单](manual-accessibility-checklist.md)：K 键盘，SR 读屏，V 视觉/偏好，M 实体移动设备，Native 浏览器/系统原生控件。**全部人工组合目前待执行**，不能用 jsdom、Playwright WebKit 或移动模拟器代替 Safari/实体设备结果。

## 使用与补齐方式

1. 回归运行失败时记录失败用例与输出，不将文件存在记为通过。只通过部分测试时，注明命令的筛选范围；全套命令和 tarball/browser 环境由本次报告统一记录。
2. Storybook 每行链接到真实 Story；`Playground` 的状态由示例实现和 args 决定。只有“禁用”Story 不代表已有禁用行为测试；无对应状态 Story 时应通过现有 Controls 或增加最小验收 fixture 后记录，不能假设该场景已被展示。
3. H/A/F 需实看焦点/hover/按压区别；D/L 需真实操作确认阻断；I 需可读错误关联；R 需确认可读可复制而不可改。静态展示组件按文本、结构、动态消息和响应式验收，不增加伪交互角色。
4. 公共语义与视觉基础还需交叉核查 [设计基础](design-foundation.md)、[工程基础](engineering-foundation.md) 和 [人工验收清单](manual-accessibility-checklist.md)。本表不宣称 WCAG 合规认证，也不替代宿主产品的完整任务验收。
