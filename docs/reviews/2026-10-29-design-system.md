# Oxygen 全组件设计检查与修正 · 2026-10-29

## 范围与设计依据

检查 UI 的全部 60 个组件源文件、4 个 patterns 和全部 55 个 Storybook 示例。检查项目覆盖文字层级、颜色、尺寸、边框、圆角、阴影、图标、交互状态、键盘、标签与错误说明、长文案、窄容器和减少动态效果。

依据：

- [Arco 官方主题定义](https://github.com/arco-design/arco-design/blob/main/components/style/theme/default.less)：采用系统字体栈、14px 正文、分层的动效与浮层；其官方站点 CSS 分开定义 text-1～4、fill、border 和 primary-light 角色。
- [Ant Design 字体规范](https://ant.design/docs/spec/font)：统一字体层级、字号与行高，保证正文与标题可读性。
- [Ant Design 色彩规范](https://ant.design/docs/spec/colors)：区分品牌、功能与中性色，按状态使用色阶。

这是 Oxygen 对共同原则的适配。沿用用户已选的 36px 默认 / 32px 紧凑 / 44px 触屏目标，以及 6px 控件 / 8px 容器圆角；没有混用两家不同的默认尺寸，也不宣称逐像素复刻或获得规范认证。

## 已完成的主要修正

1. 增加浅边框、强调边框、占位、禁用、悬停及语义色的文字/边框/底色 token。品牌蓝稍加深，解决灰底和选中浅蓝底上的小字对比度不足。
2. 加载按钮保留主色和进度表达；禁用使用中性灰，移除叠加透明度。次要按钮为白底描边，ghost 为中性操作，link 保持品牌色。
3. 控件 hover / focus / invalid / readonly / disabled 状态补齐，普通按钮最小宽度与图标方形按钮分开；补齐减少动态效果。
4. 提示使用图标、文字及语义底色共同表达；Toast / Message / Notification 默认关闭按钮同时具备 X 图标和名称。
5. 普通上传为紧凑按钮，拖拽上传有独立高度和引导。文件图标、名称、状态相邻，上传中显示进度；无预览行为的文件名不再伪装为链接。
6. 表单支持显式控件 ID、复合控件标签、Select 实际按钮的错误与必填说明、ColorPicker 实际触发器的 ARIA，以及 Slider thumb 的名称与错误说明。声明式 FieldDescription / FieldError 支持直接或 Fragment 子节点、自定义 ID、条件消失和手动关联优先；隐藏或补充声明拥有独立 ID，不会抢占可见说明及 props 说明。
7. 修复 disabled/loading asChild Button 的子节点点击及键盘 capture 绕过；保留 Tab 导航和启用时的事件顺序。
8. 修复 Slider 的小数 min / 科学计数 step 跳值。实际键盘、指针、范围、回调和 FormData 都以调用方实际单位验证。
9. Transfer 全选框在部分选择时报告 mixed；Accordion 支持方向键、Home/End，跳过禁用标题，嵌套实例独立。
10. Tabs 补齐根样式类、纵向排布与面板焦点；表格 hover 与 selected 区分；Step / Timeline 空态和加载态恢复正确列表语义；空 Tree 使用命名 group。
11. Progress 过滤非有限值、补默认本地化名称和状态描述；Skeleton 的有名称/装饰状态使用正确语义。
12. 调整卡片、分隔线、树、图片回退、统计、折叠、步骤和 patterns 的长文案与窄容器布局。StatusMessage 修正图标/正文/操作的组合布局。
13. Storybook 验收页约束表单宽度，查询按钮按内容宽度；手机布局示例侧栏改为纵向，避免挤压内容；新增完整语义色与纵向 Tabs 示例。
