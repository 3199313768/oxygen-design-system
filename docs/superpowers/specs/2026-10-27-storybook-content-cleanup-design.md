# Storybook 内容整理设计

## 目标

将 Storybook 示例调整为基础组件库的通用演示内容：文案全部使用中文，示例不携带项目、账号、文件、团队、报告等业务语义，主内容按组件职责分组展示。

## 范围

- 只修改 `apps/storybook/stories` 中的示例结构和可见文案。
- 保留 `@oxygen-design/ui`、`@oxygen-design/patterns` 的组件 API 和实现。
- 保留页面模式示例，但使用“页面标题”“导航项”“内容区域”等通用占位词。
- 不增加业务组件、数据请求、状态管理或新的交互行为。

## 结构

- `通用/基础组件`：按基础按钮、排版与间距、状态反馈、卡片展示拆分故事。
- `数据录入/表单控件`：按复选框、Tabs、菜单、Form、选择控件拆分故事。
- `导航/分页`：单独展示 Pagination。
- `反馈/浮层反馈`：保留对话框、确认框、侧栏和气泡，但统一为通用中文。
- `布局/Layout` 与 `布局/页面模式`：减少装饰性内容，保持结构示例清晰。

## 验证

- Storybook 类型检查。
- Storybook 静态构建。
- 文案扫描确认不再出现示例账号及业务领域词。
