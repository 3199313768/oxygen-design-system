# 设计与可访问性

Oxygen 面向复杂信息与高频操作，优先保证信息清晰、操作可靠和工作效率。基础组件保持业务中立，产品语义通过内容与组合表达。

## 语义 Token

组件使用 CSS Variables；优先覆盖 `--oxygen-color-*`、`--oxygen-space-*`、`--oxygen-radius-*` 等已有 Token，不向宿主注入全局业务样式。品牌色表达主要操作、选择和焦点，成功、警告、错误颜色保留各自语义。不要只靠颜色传达状态。

页面、容器、浮层通过背景、边界与适量阴影表达层级。主题切换保持组件尺寸、布局和交互一致；不对图片或视频进行整体反色。实际变量与作用域选择器以已安装的 `tokens.css` 为准。

## 排版与布局

标题级别表达文档结构，不能只为字号选择 h1–h5。正文与辅助说明保持清晰层级。组内紧凑、组间留白，优先复用 4、8、12、16、24、32 的间距尺度。默认控件高度 36px，小尺寸与紧凑控件通常为 32px；触屏环境需要保证有效点击区域可达。

窄屏允许重排和局部滚动。表格和代码可以独立横向滚动，不能让整个页面被长内容撑开。页面模式只提供结构，不承担路由、请求或权限判断。

## 组件状态

根据具体能力验证默认、hover、focus、选中、禁用、加载、错误、空和只读状态。并非每个静态组件都有禁用或加载属性；逐组件页面会说明适用范围。异步流程的失败、重试、请求取消和重复提交仍由宿主负责。

## 键盘与辅助技术

- 使用可见标签；纯图标操作提供可访问名称，占位文字不能代替标签。
- 保留可辨认的键盘焦点，按自然 DOM 顺序使用 Tab，不用正数 tabIndex 人为排序。
- 模态窗口提供标题与说明，验证焦点进入、限制、关闭和返回触发器。
- 选择、树、页签和滑块遵循各组件页面列出的方向键、Home/End、Enter/Space 等交互。
- 状态反馈用适当的 live region，不把频繁变化的整个页面设置为 alert。
- 图片提供用途合适的 alt；装饰图标对辅助技术隐藏，二维码同时提供文本地址或替代操作。

自动检查、类型检查和测试通过不能等同于真实读屏器验收。ColorPicker 当前保留 button 字段 ARIA 兼容契约，存在独立的语义迁移边界，不能将其描述为完整读屏支持。
